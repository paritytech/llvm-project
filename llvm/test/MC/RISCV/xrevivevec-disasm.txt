# The 256-bit-only operations have no 128-bit twin, so their encodings with the
# width bit set decode as nothing, extension or no extension. These two are the
# exponentiation and sign-extension words above with that bit added.

# CHECK-NO-EXT: invalid instruction encoding

# CHECK-INVALID: invalid instruction encoding
# CHECK-NO-EXT: invalid instruction encoding
